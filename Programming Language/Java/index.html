Sub-pillar 9.5 · Java

Học Java đúng cách

Java là ngôn ngữ của hệ thống lớn — ngân hàng, viễn thông, thương mại điện tử, Android. Sub-pillar này dạy Java 21 LTS với cú pháp hiện đại (record, sealed, switch expression, text block, virtual thread), không phải Java 8 của mười năm trước. Trọng tâm: hiểu vì sao JVM, Collections, Generics và mô hình bộ nhớ được thiết kế như vậy — chứ không chỉ nhớ cú pháp.

Java 21 LTS · 14 chương · ~20,000 dòng · 70 bài tập + 110 quiz

Vì sao vẫn học Java năm 2026?

🧠 Mental model

Java không còn là ngôn ngữ "hot" trên mạng xã hội, nhưng nó vẫn chạy phần lớn hệ thống backend quan trọng của thế giới: ngân hàng lõi, thanh toán, viễn thông, sàn thương mại điện tử, dữ liệu lớn (Hadoop, Spark, Kafka đều viết bằng Java/Scala trên JVM), và toàn bộ Android.

Điều đó có nghĩa: nhu cầu tuyển dụng ổn định, hệ sinh thái cực kỳ trưởng thành, và — quan trọng nhất với người học — Java buộc bạn phải nói rõ mọi thứ. Kiểu dữ liệu tường minh, ngoại lệ được kiểm tra, mô hình bộ nhớ rõ ràng. Học Java xong, bạn hiểu được vì sao Python hay JavaScript chọn làm khác.

Write once, run anywhere. Khẩu hiệu của Java từ 1995 — và cơ chế đứng sau nó (biên dịch ra bytecode rồi để JVM lo phần còn lại) chính là chìa khoá để hiểu mọi thứ khác trong ngôn ngữ này.
💡 Đối tượng phù hợp

Người mới hoàn toàn — Java dài dòng hơn Python nhưng chính sự dài dòng đó khiến mọi khái niệm (kiểu, phạm vi, đối tượng, tham chiếu) trở nên hiển hiện, không có gì ngầm ẩn.
Đã biết Python/JS — mỗi chương có callout đối chiếu, chỉ rõ chỗ Java làm khác và vì sao.
Chuẩn bị phỏng vấn — các mục "Góc phỏng vấn" nêu đúng những câu hay được hỏi: HashMap hoạt động thế nào, equals/hashCode, type erasure, String pool, deadlock.

⚠️ Cảnh báo về tài liệu Java trên mạng

Phần lớn tutorial Java tiếng Việt vẫn dừng ở Java 8 (phát hành 2014) — dùng Date thay LocalDate, Vector/Hashtable thay ArrayList/HashMap, viết getter/setter tay thay record, và switch kiểu cũ với break ở mọi nhánh.

Sub-pillar này lấy Java 21 LTS làm chuẩn và ghi rõ phiên bản cho từng tính năng, để bạn biết code của mình chạy được ở đâu. Nơi nào cách viết cũ vẫn hay gặp trong dự án thật, chúng ta học cả hai — nhưng luôn nói rõ cái nào nên dùng.

Java trong bức tranh Pillar 9

Mỗi chương có mục "Kết nối" trỏ tới chương tương ứng ở sub-pillar khác. Ba đối chiếu đáng chú ý nhất:

  • Chương 7-8 (Collections & Map) ↔ Python Chương 3 (Data Structures) — Java tách rạch ròi interface và implementation, Python gộp tất cả vào bốn kiểu dựng sẵn.
  • Chương 9 (Generics) ↔ JavaScript Chương 10 (Generics & Utility Types) — cả hai đều xoá kiểu lúc chạy, nhưng vì lý do hoàn toàn khác nhau.
  • Chương 10 (Stream API) ↔ Python Chương 9 (Iterators & Generators) — Stream lười giống generator, nhưng dùng chuỗi phương thức thay vì yield.

Java cũng nối chặt với các trụ cột nền tảng: OOP (trụ cột 6) tìm được ví dụ cụ thể nhất ở đây; DSA (trụ cột 2) dùng Collections làm công cụ; Database (trụ cột 5) gặp lại ở Chương 13 (JDBC); OS (trụ cột 3) giải thích luồng và bộ nhớ ở Chương 12.
