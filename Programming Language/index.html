Triết lý giáo trình

3 nguyên tắc xuyên suốt 63 chương — khác với hầu hết tutorial trên internet.

Nguyên tắc 1

Mental model trước cú pháp

Không dump cú pháp khô. Mỗi feature bắt đầu bằng "vì sao có cái này", sau đó mới đến "cách dùng". Học ngôn ngữ là học cách suy nghĩ — không phải nhớ keyword.

Nguyên tắc 2

Modern first, không cú pháp deprecated

Dart 3 / Material 3 / ES2024 / Python 3.12+ / Java 21 LTS — tất cả là baseline. Không dạy var kiểu cũ, không dạy callback hell, không dạy Python 2.

Nguyên tắc 3

Tooling là first-class

Mỗi sub-pillar có chương cuối dành riêng cho tooling production (Vite, tsconfig, pyproject, pytest, build & deploy). Không scatter rải — học bài bản, một lần.
