Giáo trình OS
Hệ điều hành — từ kernel đến memory

Tài liệu mô tả chi tiết toàn bộ nội dung 10 chương Hệ điều hành: process, thread, concurrency, deadlock, memory, file system. Đọc trước để có cái nhìn tổng quan, sau đó vào từng chương để học sâu. Mỗi chương kèm ví dụ Linux/Node.js, bài tập, quiz và sơ đồ ASCII.

⚙️ Triết lý học OS của giáo trình
  1. Hiểu tại sao trước hiểu cái gì. Mọi cơ chế OS sinh ra để giải quyết bài toán cụ thể (vd: virtual memory ra đời vì RAM quá ít cho nhiều process).
  2. Nối với code thật. Mỗi khái niệm có ví dụ shell command (Linux) hoặc Node.js — không trừu tượng.
  3. Phỏng vấn-oriented. Tập trung vào câu hỏi hay xuất hiện: process vs thread, deadlock, virtual memory, GC...
  4. Thực hành trên máy thật. Mở terminal mà thử ps, top, strace. OS không phải lý thuyết suông.

🎯 Mục tiêu học tập

  • Hiểu MLFQ (Multi-Level Feedback Queue) — gần với Linux CFS
  • Hiểu hiện tượng "convoy effect", "starvation" và cách giải quyết
