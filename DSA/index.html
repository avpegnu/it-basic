Tại sao học DSA?

DSA (Data Structures & Algorithms) là nền tảng tư duy lập trình. Thiếu nó, bạn vẫn có thể code app nhỏ, nhưng:

  • Phỏng vấn: 90% công ty lớn (FAANG, fintech, product company VN) đều test DSA ở vòng coding.
  • Code production: Biết chọn đúng cấu trúc dữ liệu = code chạy nhanh hơn 100x mà không cần "tối ưu".
  • Đọc code người khác: Hiểu vì sao thư viện chuẩn dùng Hash Map, vì sao database dùng B-tree, vì sao Redis có sorted set.
  • Tư duy: DSA dạy bạn phân rã bài toán — kỹ năng này dùng ở mọi nơi, không chỉ trong phỏng vấn.

Cách dùng tài liệu này

  1. Đọc giáo trình tổng quan trước (5-10 phút) để có cái nhìn toàn cảnh 12 chương.
  2. Học tuần tự: Chương 01 → 02 → ... → 12. Đừng nhảy cóc — kiến thức xếp tầng.
  3. Mỗi chương: đọc lý thuyết → xem visualizer → tự code lại bằng JS/TS → làm quiz → giải bài LeetCode tiêu biểu.
  4. Đúng >= 80% quiz mới chuyển chương. Sai ở đâu, đọc lại phần đó.
  5. Sau khi xong cả 12 chương: bắt đầu LeetCode NeetCode 150 theo pattern.
  6. Mỗi 2 tuần quay lại review lại 1 chương — DSA chỉ ngấm khi ôn lại nhiều lần.
