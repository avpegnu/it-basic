Cách học hiệu quả

Bộ giáo trình thiết kế cho self-study trong 4-6 tháng. Đây là lộ trình khuyến nghị.

Lộ trình 7 tháng

  1. Tháng 1 — CLI + DSA căn bản: master terminal + 6 chương đầu DSA (Big-O, Array, Linked List, Stack, Hash, Recursion).
  2. Tháng 2 — DSA nâng cao + OS: 6 chương cuối DSA (Tree, Heap, Graph, DP) + bắt đầu OS.
  3. Tháng 3 — OS + Networking: finish OS + đi qua Networking chương 1-7.
  4. Tháng 4 — Networking + Database: finish Networking + Database chương 1-7 (SQL → ACID).
  5. Tháng 5 — Database + OOP: finish Database + OOP/Design Patterns đầy đủ.
  6. Tháng 6 — System Design: System Design 8 chương + practice case study + ôn cross-pillar.
  7. Tháng 7 — DevOps: 14 chương DevOps (Foundations → CI/CD → Docker/K8s → IaC/Cloud → Observability → SRE → DevSecOps → Production).
Tốc độ đi cuối cùng phụ thuộc vào việc bạn có code thật không. Đọc 100 dòng lý thuyết < 1 giờ động tay implement. Mỗi chương kết thúc bằng quiz và bài tập — đừng skip.
