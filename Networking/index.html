Tại sao học Networking?

Mọi app web/mobile/cloud đều "nói chuyện" qua mạng. Không hiểu network, bạn vẫn code được — nhưng:

  • Phỏng vấn: backend/DevOps/SRE đều hỏi: TCP handshake, HTTPS, DNS, JWT, CORS, load balancer.
  • Debug production: hiểu network giúp đọc curl trace, Wireshark, log nginx; tìm bug "vô lý" như request stuck, slow response.
  • Tối ưu hiệu năng: biết HTTP/2 multiplexing, CDN, keep-alive — tăng tốc app gấp nhiều lần.
  • Hiểu công cụ: nginx, Cloudflare, Kubernetes Service, Kafka — đều xây trên network primitives.

Xem trước — TCP 3-way Handshake

Đây là sơ đồ bạn sẽ học chi tiết ở Chương 03:

Client Server ────── ────── ──── 1. SYN ────▶ (seq=x) [LISTEN] ◀── 2. SYN+ACK ── (seq=y, ack=x+1) [SYN_SENT] [SYN_RCVD] ──── 3. ACK ────▶ (ack=y+1) [ESTABLISHED] [ESTABLISHED] ──────── Connection ready, exchange data ────────

3 packet để mở connection: SYN → SYN-ACK → ACK. Sau đó cả 2 đều ESTABLISHED, sẵn sàng gửi data.
